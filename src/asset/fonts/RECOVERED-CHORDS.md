# Recovered Chords Std

`RecoveredChordsStd-Regular.ttf` is the file supplied by the user, preserved
without modification. Its internal version identifies it as a partial font
reconstructed from four PDF exports, with 29 glyphs including .notdef.
It is not the complete Pori font. Its original family name is retained.

The single "Fuente de la hoja" selector applies the selected font to headings,
metadata, sections, structure, notes, lyrics and chords. New sheets default to
Recovered Chords Std. Older separate text/chord settings migrate to the chord
choice; saving removes the obsolete chord-specific setting.

The font and its embedded SIL Open Font License 1.1 are bundled locally.
The same license is also preserved in `RecoveredChordsStd-OFL.txt` and exported
with the font in HTML EPUBs. No online font service or system installation is needed.

`chordTypography.js` translates normal chord notation to the recovered font's
legacy glyph codes for display only. Stored chord names remain unchanged.
Missing glyphs use the bundled Libre Baskerville font; suffixes retain their
superscript position. The text face restricts coverage to the usable prose
glyphs (A-G, parentheses and slash), avoiding superscript digits, the chord 6/9
glyph mapped to `%`, and musical symbols mapped to punctuation. The full font
is exposed separately as `Recovered Chords Std Chords` for chord rendering.
The editor, PDF and EPUB share these faces and page styles. A complete text
font is needed to give the missing letters the same appearance.
